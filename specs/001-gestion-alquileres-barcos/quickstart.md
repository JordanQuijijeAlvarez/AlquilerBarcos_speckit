# Quickstart (AlquilerBarcos)

Objetivo: Disponer de pasos mínimos para iniciar el desarrollo local del proyecto (basado en Vite + TypeScript + Tailwind).

1. Inicializar proyecto con Vite + TypeScript (siga las guías oficiales).
2. Configurar TailwindCSS según la guía de integración con Vite.
3. Crear estructura de carpetas: `src/models`, `src/services`, `src/controladores`, `src/ui`, `src/utils`.
4. Añadir scripts de desarrollo y build en `package.json`.
5. Ejecutar servidor de desarrollo (`npm run dev`) y abrir la app en el navegador.

Notas:
- Mantener el código en TypeScript y seguir la `Constitution` para reglas y restricciones.
- Ejecutar pruebas con `vitest` si se instala (recomendado para calidad académica).
